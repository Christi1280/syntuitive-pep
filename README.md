# SYNTUITIVE PEP — Website design prototype

Open `index.html` in a browser. For development, use VS Code Live Server or `python -m http.server 8000` from this folder.

This is a complete **navigable front-end design prototype**, not a deployed production application.

## Included
- Public landing page
- Student dashboard
- Grade 6 learning center, subjects, topic and lesson templates
- Practice hub and functioning sample quiz
- Interactive sample flashcards
- Quiz Arena concept
- Progress dashboard (sample quiz attempts saved locally in browser)
- Achievements and settings templates
- Admin Studio concept
- Past papers and mock examination placeholders
- Responsive desktop and mobile layout

## Not yet implemented
- Real student accounts, authentication or database
- Complete lessons, past-paper uploads, question bank or official examination content
- Actual timed mock exams, multiplayer, badges or parent accounts
- Secure admin permissions
- Grade 4/5 content

Subject topics are **illustrative**, not a verified complete curriculum map. No actual student data is collected. The design uses Google Fonts when online, with system fallbacks.
